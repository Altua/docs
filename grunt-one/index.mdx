**Create with AI. Refine visually. Deliver in PowerPoint and on the web.**

Grunt ONE brings AI creation, visual editing, PowerPoint, and HTML reporting together around the same Grunt objects. You can build on your charts and tables as work moves from an AI conversation to a presentation or report.

If you produce financial analysis, management reports, or consulting presentations, you often need the same visual in several places. Grunt ONE connects those workflows so you spend less time rebuilding content and more time refining the result.

<Note>
  Grunt ONE is being delivered in stages. Live PowerPoint control, interactive HTML refresh, continuous synchronization, and customer-hosted deployment are still in development. Confirm the capabilities enabled for your organization before planning your rollout.
</Note>

## What Grunt ONE brings together

| Part of the product | What it helps you do |
| --- | --- |
| AI connection through MCP | Ask a compatible assistant to create and revise Grunt charts and tables. |
| Web Editor | Refine an object's data and presentation visually in your browser. |
| PowerPoint integration | Use Grunt assets in presentations and edit supported objects with the Grunt add-in. Live control through Claude for PowerPoint is in development. |
| HTML skill | Guide an AI assistant in assembling reports with Grunt visuals. Interactive refresh and offline saving are being completed. |
| Synchronization | Preserve source identity and saved versions. Continuous updates between connected surfaces are planned. |
| Client Console | Manage your subscriptions, seats, administrators, and integration access. Deployment management is being completed. |

MCP, the Model Context Protocol, is the connection that lets an AI assistant use Grunt's tools. A skill provides instructions that guide the assistant through a workflow, such as assembling an HTML report.

## Keep the work behind the visual

A Grunt object contains its data, settings, and formatting rules as well as its appearance. People and AI can work with that structure to revise the result.

For example, you can create a revenue waterfall with an assistant, refine it in the Web Editor, and use selected versions in PowerPoint and an HTML report. Grunt can render the chart for each placement while keeping its source and saved version identifiable.

A placement can remain linked to its source, become an independently editable Grunt object, or be delivered as a saved snapshot. The workflow determines which connection you keep. See [Connected workflows](/grunt-one/connected-workflows) for the differences.

## From analysis to delivery

For a monthly performance review, the intended Grunt ONE workflow is:

1. Ask your assistant to create charts and tables from your figures.
2. Refine the data, labels, colors, and layout in the Web Editor.
3. Use the selected versions in a PowerPoint presentation.
4. Produce an HTML report with supporting commentary and Grunt visuals.
5. Review revisions and choose which outputs should adopt them.
6. Manage team and integration access through the Client Console.

The complete workflow depends on the capabilities included in your release. Review the rollout status below when choosing an evaluation scope.
